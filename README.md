# Stephanie Onwuagbaizu: Product Portfolio

A Next.js 14 App Router portfolio built with TypeScript and Tailwind 3.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
```

## Content

- Edit portfolio links and contact details in `lib/site.ts`.
- Edit case-study metadata and source documents in `lib/caseStudies.ts`.
- Public assets belong in `public/`.
- The resume is served from `public/Stephanie Onwuagbaizu Resume - Product Management.pdf`.

## Routes

- `/` - Portfolio overview
- `/case-studies` - Product case studies
- `/experience` - Professional experience
- `/toolkit` - Tools and product skills
